INSTRUCCIONES: Configuración SSL para IHSStatus Plugin

El plugin IHSStatus ahora soporta certificados SSL autofirmados. Sigue estos pasos:

1. REEMPLAZAR ARCHIVO:
   - Descargar el nuevo ihs_status_to_appd.py desde:
     https://github.com/ulix1808/appdyIBMIHS/blob/main/alternativas-hpux/IHSStatus/ihs_status_to_appd.py
   - Reemplazar en: /app/agent_machine_ihs/monitors/IHSStatus/ihs_status_to_appd.py

2. CONFIGURAR CERTIFICADO SSL (elegir una opción):

   OPCIÓN A - Deshabilitar verificación (rápido):
   Agregar en env.sh o variables del Machine Agent:
   export SSL_VERIFY="false"

   OPCIÓN B - Cargar certificado CA (recomendado):
   a) Obtener certificado:
      openssl s_client -showcerts -connect 10.10.10.94:40443 </dev/null 2>/dev/null | \
        openssl x509 -outform PEM > /app/agent_machine_ihs/monitors/IHSStatus/ihs-ca.pem
   
   b) Configurar variable:
      export SSL_CERT_PATH="/app/agent_machine_ihs/monitors/IHSStatus/ihs-ca.pem"

3. APLICAR CAMBIOS:
   - Si usas env.sh: source /app/agent_machine_ihs/monitors/IHSStatus/env.sh
   - Reiniciar Machine Agent
   - Probar: cd /app/agent_machine_ihs/monitors/IHSStatus && python3 ihs_status_to_appd.py

Documentación completa: INSTRUCCIONES_SSL_CERTIFICADO.md en el repositorio.
